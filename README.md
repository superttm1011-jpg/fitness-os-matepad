# Fitness OS V5.0｜长期稳定版

为 **华为 MatePad 11** 优化的双人、离线优先训练与健康记录网页应用，已从 V4.7 的稳定界面一次性整合训练、复盘、营养与安全修复。

## 适用范围

- 双人档案：本人「推—拉—腿—休」与爱人非连续日全身力量训练；训练记录、餐食、健康指标、恢复评分分开保存。
- 训练：动作分帧示意（RepDB 免费许可）、逐组重量次数/RPE、透明的双重渐进规则、减量模式、休息计时。
- V5 改善：训练逐组自动暂存；「仅保存进度」「提前结束并保留当前训练日」「完成并进入下一日」分别操作；切换训练日保护草稿。
- 长期趋势：近7日训练与前7日比较、记录餐食的天数与平均摄入、等权7日体重与腰围趋势；避免把漏记当作零摄入。
- 个性设定：本人和爱人单独设置身高、体重目标、腰围目标、睡眠目标、手动复查日期、史密斯杆质量与滑轮口径。
- 安全：数据库键保持 `FitnessOS_Duo_V4 / family`，JSON 双人备份与 AES-GCM 加密备份，导入预检与先写入后切换，保留旧 V4 数据。

> 本应用不是医疗设备，不具备自动识别动作准确性、疾病诊断或临床运动处方能力。疼痛、胸闷、眩晕或出血等异常时应停止训练并就医。备孕、妊娠和血糖异常等问题应按医生个体化意见管理。

## 发布方式

仓库 https://github.com/superttm1011-jpg/fitness-os-matepad 已采用 **main / (root)** 分支部署 GitHub Pages。将发布 ZIP **解压后的目录内容**放在仓库根目录，覆盖原文件并 Commit，即会触发 Pages 发布。无需新建仓库或修改 Pages 设置。`.github` 工作流不是此发布方式的必需文件。

部署地址：https://superttm1011-jpg.github.io/fitness-os-matepad/

**上线前**先在 V4.7「设置」中导出加密双人备份并将备份留在私人设备，不要传到公开 GitHub 仓库。新版本首次打开后核对双人训练、饮食、体检数据以及旧计划；再测试断网打开、缓存 RepDB 图片、关闭重开后的记录留存。这些真实 MatePad 行为需用户实机验证。

由于本人和爱人共用一个平板，设备浏览器内的存储是本机持有，不提供远端账号同步。**即使以后不发布新版本，也要定期保存加密 JSON 备份**，以防浏览器清理、设备损坏或恢复出厂设置。

## 许可与资源

RepDB 免费图像数据用于本应用内教学，须保留可见署名 **[Exercise data by RepDB (repdb.co)](https://repdb.co)**；不能将图片或派生数据重新包装为独立的数据集。免费素材是 512×512 WebP 静态起止姿势，不是连续动作视频。图像版本固定为 `RepDB/exercise-dataset@66c4298af8d99b9dc397dad6699e508fb871d249`，联网点击图片缓存后再离线使用。源许可： https://github.com/RepDB/exercise-dataset/blob/main/LICENSE-DATA.md

## 自动化检查

- `python tests/verify_release.py`：发布包、隐私、版本与资源检查。
- `node tests/final_engine.test.cjs`：数据校验、饮食和训练指标、进阶安全规则。
- `python tests/browser_final_smoke.py`：浏览器模拟横竖屏、双人、训练提前结束/完成、器械配置、动作界面。测试使用 Chromium 和 Playwright。

测试不等于生产环境 HTTPS/IndexedDB 的持久性验收；需在用户真实 MatePad 上验证。
