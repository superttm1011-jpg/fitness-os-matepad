# Fitness OS V4.2 — 华为 MatePad 双人训练与健康管理

本仓库**只能包含公开、无个人数据的网页软件源文件**。请勿上传个人 JSON 备份、医院报告、手机号、姓名、密码、截图或任何医学化验结果。

## 上线（GitHub Pages）

1. 先在旧版软件设置页导出一次**加密备份**，只保存在私有设备上。
2. GitHub 新建一个**独立**的公开仓库，建议 `fitness-os-matepad`（不要使用已有基金投资仓库）。
3. 解压本发布包，将其文件与文件夹上传到新仓库 **main 分支根目录**（必须保留 `.github/workflows/deploy.yml`、`tests/`、`assets/`、`icons/` 与 `.nojekyll`）。
4. GitHub 仓库 **Settings → Pages → Build and deployment → Source: GitHub Actions**。
5. 打开 **Actions**，检查 `Publish Fitness OS to GitHub Pages` 工作流运行成功。成功后 Pages 显示实际访问地址，通常为 `https://<你的GitHub用户名>.github.io/fitness-os-matepad/`，**请以GitHub实际生成地址为准**。
6. 在华为 MatePad 浏览器打开新网址，进入设置→查看本机存储，并分别用本人/爱人测试保存一条**虚拟数据**、切换档案、刷新重开；删除虚拟数据。
7. 打开浏览器菜单中的 **添加至桌面**。在 HarmonyOS 5+ 下通常可从网页菜单 `∷ → 添加至桌面`，具体以设备页面为准。
8. 从软件内「设置」导入你本地保存的旧版备份；核对两人的训练历史、饮食与体检记录是否完整。
9. 断开 Wi-Fi/网络，再打开桌面图标，确认离线可使用，恢复网络。

> 重要：上传此 ZIP 文件到 GitHub 仓库**不会自动解压和发布**，需要上传解压后的文件（或用 GitHub Desktop / Git 命令）。

## 数据迁移与隐私

- GitHub Pages 是**公开网页**，即使用户账号私密也不可把个人健康数据打包上传。
- 本应用默认用 IndexedDB 在当前浏览器和网站源下存储个人记录；服务端只托管静态代码和图片。
- 改域名、换浏览器、清除网站数据、换平板会导致数据看似不见，需要手动从 JSON 备份恢复。不能保证浏览器永久保存。
- 备份最好选**加密 JSON**，妥善保存密码；不要把备份上传到 GitHub 仓库。
- 一台平板两人切换为应用层隔离，并**非操作系统级访问控制**；能操作平板的人可能访问双方的记录。
- 不要将仓库改用于收集个人身份信息、医疗报告或公开分享健康数据。
- 初次打开或升级后必须联网等待离线资源完整加载；安装前确认已做备份。

## 发布包特征

- `index.html` + `sw.js` + `manifest.webmanifest` + `assets/` + `icons/`：真正的静态PWA文件，不含任何个人数据。
- `tests/verify_release.py`：在 GitHub Actions 发布前扫描必需文件、版本和公开构建中的敏感信息。
- `.github/workflows/deploy.yml`：提交到 main 后自动校验并部署站点。
- `sw.js`：应用启动网络优先、离线回退；静态资源按版本缓存。
- 维持原有 `FitnessOS_Duo_V4` 数据库名和 V4 JSON 结构，减少已在同源网页使用 V4 的升级迁移风险；不同域名仍需备份导入。
