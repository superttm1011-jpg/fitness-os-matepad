# Fitness OS V4.1 — 华为 MatePad PWA

## 安装路径（推荐）

1. 先在原 V3/V4 软件的「设置」中导出双人完整备份（建议加密）；**不要上传备份到 GitHub**。
2. 将此文件夹中的静态资源部署至自己的可信 HTTPS 站点根目录（例如 GitHub Pages / Cloudflare Pages）。这里只上传代码与静态素材，不上传训练、体检和家庭备份。
3. 华为 MatePad 浏览器打开网址，等待首次加载结束，检查操作和保存记录，再使用浏览器「添加至桌面」；不同 HarmonyOS 版本可能只是浏览器快捷方式。
4. 在新网址的「设置」导入旧版 JSON 双人备份；核对本人和爱人数据后做一次测试记录，关闭浏览器再打开确认仍保存。
5. 打开一次网页并等待资源缓存后，再断网测试；缓存验证通过后才能依赖离线功能。

## GitHub Pages 部署（无需命令行）

在 GitHub 新建只存放软件**代码**的仓库，上传本文件夹的所有内容到仓库根目录，进入 Settings → Pages，选择 Deploy from a branch，指定 main/(root)。实际发布网址由 GitHub 生成，必须由仓库持有人配置。切勿将个人健康资料、备份文件、密码上传公共仓库。

## 局限

- PWA 是网页应用，不是鸿蒙原生 HAP；是否提供单独安装入口取决于 MatePad 所用浏览器。
- 数据存于当前网址对应的浏览器 IndexedDB；改换网址、浏览器或清站点数据不会自动同步。
- 食品库使用手工输入营养标签，每100g数值；没有实时联网条码搜索。
- 扩展动作库是独立整理的18项家庭器械动作，没有直接引用 Free Exercise DB 图片素材。
- 医疗相关化验指标仅供记录，不能自动诊断疾病。
